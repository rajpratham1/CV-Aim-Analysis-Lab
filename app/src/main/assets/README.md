# Model Assets Directory

Place your `.tflite` object detection models here (e.g. `ssd_mobilenet_v1.tflite`).

To use your model:
1. Copy the `.tflite` model file into this directory.
2. In the app, open **Settings > Model Integration**.
3. Enter the model filename (e.g. `ssd_mobilenet_v1.tflite`).
4. In **CV Lab**, import an image and run the detection pipeline.

See `docs/MODEL_INTEGRATION.md` for expected input/output tensor specifications.
